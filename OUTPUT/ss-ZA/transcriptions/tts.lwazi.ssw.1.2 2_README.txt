1. GENERAL INFORMATION:
----------------------------------------

These are recordings and phonetic alignments designed to be used for
building a TTS system. The text was selected for minimal diphone
coverage.

Language: One language per directory, identified by its ISO language name abbrviation.


2. LICENCE:
----------------------------------------

Refer to the "LICENCE" file in this directory.


3. TECHNICAL:
----------------------------------------

Description of files:

README.txt             -    This file.
LICENCE.txt            -    Text file containing licensing information.
PHONESETMAP.txt        -    Mapping between phone representations and XSAMPA representations.
wavs/*.wav             -    Recordings in 16bit 16kHz RIFF format.
textgrids/*.TextGrid   -    Phonetic transcriptions (in utf-8 "Praat" text file).
etc/utts.data          -    Orthographic transcriptions (in utf-8 "Festival" text file).
